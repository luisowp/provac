# Prueba mínima de GitHub

Este archivo contiene una instrucción que un agente puede leer y aplicar.

## Entrada de prueba

PRUEBA GITHUB

## Instrucción

Cuando Luiso solicite esta prueba, lee este archivo y responde exactamente:

> Luiso, leí la instrucción desde GitHub y pude aplicarla.

## Funcionamiento

GitHub conserva el archivo y el historial de cambios. El agente consulta la instrucción y produce la respuesta. Esta prueba no configura ejecución automática.
