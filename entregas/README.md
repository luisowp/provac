# Entregas de agentes

Use un archivo nuevo por aportación en <agente>/<archivo>. La plantilla identifica tarea, versión y fuentes. No borrar entregas anteriores. Si no hay acceso de escritura, devolver la aportación en la conversación para incorporarla después.

PROPUESTA identifica una aportación aún no integrada. INTEGRADO identifica una incorporación decidida por Luiso. Un estado de revisión de etiquetas no acredita un hecho ni valida una firma.
